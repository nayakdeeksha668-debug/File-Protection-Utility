
# File Protection Utility

## Project Description
File Protection Utility is a Python-based application
that protects files using encryption and restores
them using decryption.

## Features
- Encrypt files
- Decrypt protected files
- Generate a secret encryption key
- Restore original file content
- Simple menu-driven interface

## Technologies Used
- Python
- Cryptography Library
- VS Code

## How to Run

1. Install Python.
2. Install the cryptography library:

   pip install cryptography

3. Run the program:

   python file_protection.py

## Project Modules
1. Key Generation
2. File Encryption
3. File Decryption
4. Main Menu
